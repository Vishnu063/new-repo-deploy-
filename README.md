# LaunchBoard

A modern, responsive task dashboard built using only HTML, CSS and JavaScript.

## Application features
- Add, complete, and delete tasks
- Filter tasks by status
- Overview cards for total, completed, and remaining tasks
- Responsive layout and mobile navigation
- Browser localStorage persistence (data is stored per browser/device)
- No backend, account, build process, or application dependencies required

## Run the website locally
Open `index.html` in a browser. Alternatively, for a simple local preview, run `python3 -m http.server 8000` from the project folder and visit `http://localhost:8000`.

## Files
- `index.html` – page structure
- `styles.css` – visual styling and responsive layout
- `app.js` – all task interactions and storage

## Note
This repository contains **application code only**. Deployment configuration, CI/CD, Docker and server setup are intentionally not included.

The optional Google Fonts stylesheet needs an internet connection; system fonts are used automatically if it is unavailable.
